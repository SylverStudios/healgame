## Clustered themes

### A. Trash mobs as teachers *(broader design topic)*

**Notes:** #1 · **Answered**

Trash today mostly pays XP. Goal: packs that threaten a little **and** run a
**minor version of the boss move**, so the boss is a louder exam, not a new
language.

**Design frame (trash as curriculum)**

| Beat | Trash job | Boss job |
|------|-----------|----------|
| Telegraph | Short cast / obvious wind-up | Longer / deadlier version |
| Fail state | Chunk of party HP / scary but recoverable | Soft-enrage or wipe pressure |
| Answer | Same button / same read as boss | Same answer, tighter window |
| Reward | XP + “I practiced that” | Clear + power |

**Idea seeds**

- Per dungeon: author **one signature boss verb**, then 1–2 trash casts that are
  the same verb at 40–60% intensity (shorter duration, less damage, longer
  cast so it’s easy to see).
- Ash Gate sketch: if boss does Tunnel Vision / Emberfall-style pressure,
  trash husk does a baby focus or baby ground DoT — player sees the timer
  (#9) and practices reacting with heals / Vowstrike / positioning of attention.
- Don’t add esuna (#13 answered no). Reaction verbs for now: **heal through**,
  **interrupt (maybe)**, **kill the caster**, **swap target attention**.
- Threat bump: slightly more overlapping damage, not more HP sponges.
- This is a content + ability authoring project (`enemyAbilities/`, mob defs,
  dungeon scripts) as much as a UI one.

**Still exploring**

1. First dungeon to retrofit — Ash Gate only, or wait for a mid dungeon as the
   “mechanic dungeon”?
2. How many unique trash verbs across the PoC — one per dungeon, or a shared
   library of 3 verbs reused with skins?

### D. Theme commitment → mid-game “discovery” evolve

**Notes:** #6 · **Direction pinned, details open**

Vampire Survivors–style: commit to enough of the same theme → **discover** a
promotion / unique combo. Mid-game, not a day-1 fork.

**Idea seeds (need more thought)**

- **Theme counters** on chip tags (Mend / Vow / Bonk / Brink / Tempo…). After
  N picks in one tag (or a specific pair), unlock a **Discovery** beat:
  rename + still swap + one signature effect or fused chip.
- VS analogy: weapons evolve when you hold item A + item B — here
  `chip theme A × chip theme B` or `N× same theme` → unique card.
- Keep it rare (one promotion per run / per campaign) so it feels like a
  landmark, not another draft.
- Do **not** require the full weapon triangle (#19) to ship this — themes can
  be playstyle verbs (Sustain / Tempo / Burst / Brink).

**Still exploring**

1. Trigger: N chips of one tag, or specific dual-theme recipes (more VS)?
2. Reward weight: cosmetic + one chip, or a real kit morph (new spell behavior)?
3. Cards-mode only, or a fantasy we eventually want in radial/lattice too?

### H. Cooldown identity — explore *(active design space)*

**Notes:** #18, #20, #24 · **Answered direction: explore, don’t lock**

**Playtest failure mode:** player was fine on mana, starved on **output**.
First free CD was Still Waters (`freeNextHeal`) — a mana panic button. Dead
card for that build. Fixed unlock order + single-purpose CDs create
build-lottery feels.

**What exists today** ([`cooldowns.ts`](../game/src/data/cooldowns.ts))

| CD | Verb | Helps when… | Fails when… |
|----|------|-------------|-------------|
| Still Waters | Free next heal | OOM / mana crisis | Mana is fine, heals too weak |
| Frenzied Liturgy | −1 mana for 30s | Sustained casting | Already cheap / already OOM from output gaps |
| Wrath Ascendant | +2 heal for 12s | Output crisis | Mana crisis (casts more, drains faster) |

So we already have mana-axis and output-axis CDs — the problem is **which one
you get when**, and whether CDs can bend toward the player’s actual deficit.

#### Exploration axes (not decisions)

**Axis 1 — Choice at unlock**

- At the CD unlock level, pick **one of three** (Still / Frenzy / Wrath), or
  pick a **role**: Panic Mana / Tempo / Output Burst.
- Vowstrike stays a separate spell unlock; majors are the flexible slot.

**Axis 2 — Authored chips on the CD card**

- CD has slots like spells; trio might be `stronger free` / `convert to +heal
  flash` / `shorten CD` — so Still Waters can *become* an output tool via chip.
- Keeps the “I drafted this” fantasy; combo power is authored, not emergent.

**Axis 3 — Dynamic modifiers (wrap the next spell)**

- CD press applies a **verb** to the next cast: Double · Echo · Instant ·
  Free · Empower · AoE wrap…
- Always relevant: you wrap whatever spell your build actually uses.
- Game-breaking allowed when chip + wrap + spell line up (echo + cheap mend,
  double + wrath window, etc.).

**Axis 4 — Hybrid “stance CD”**

- One button, mode depends on deficit or player toggle: empty mana → free cast
  behavior; full mana → empower behavior. Reads smart; risks feeling muddy.

**Axis 5 — Offer the deficit**

- On unlock (or on level-up draft), look at recent fight telemetry (mana wasted
  vs party HP crises) and **bias the offer** toward Output vs Mana. Still a
  player pick among 2–3, but the menu understands the playtest failure.

#### Sketch: three strawmen to react to

1. **Pick-a-CD at 6** — choose Still / Liturgy / Wrath. Simple; no new engine
   verbs. Chips later specialize.
2. **Wrap bar** — majors become Double / Echo / Instant (names TBD). Old
   identities become chips or retire. Maximum “always useful”; biggest redesign.
3. **Still Waters can mutate** — keep names; first chip trio on Still includes
   an escape hatch that turns it into a mini-Wrath (next heal +N instead of
   free). Least scary ship path; teaches the lesson from the playtest.

**Lean for now:** explore in writing + maybe a tabletop matrix before engine
work. Bias toward **player choice at unlock** + **room for broken combos**
without committing to full wrap-verbs yet.

**Still exploring**

1. Prefer strawman 1, 2, 3, or a mix (pick at 6 + mutate chips)?
2. How wild should combos get in PoC — “wow” or “break the Maw”?
3. Are major CDs off-GCD wraps only, or do some stay channeled/windows?

### J. Encounter verbs — interrupt yes?, esuna no

**Notes:** #13, #15 · **Esuna out; interrupt open; summons open**

- **No esuna / cleanse spell for now.** Kit is too small; cleanse tends to be
  a boring dedicated button. Prefer verbs that reuse existing presses
  (heal through, interrupt, kill add).
- Status **display** (#9) makes Emberfall / Tunnel Vision readable so “heal
  through / wait out” is a conscious choice.
- **Boss summon** still a good trash→boss curriculum beat (baby add spawn →
  boss add spawn).
- Cling DoT until full (#22): later bosses only.

**Still exploring**

1. Is interrupt worth its engine + tutorial cost if it only gates one dungeon?
2. Soft miss (big damage) vs hard miss (wipe) if we do interrupt?
3. Can “must use Vowstrike” mean damage amped on the cast target instead of a
   formal interrupt flag?
